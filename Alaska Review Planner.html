Alaska is reviewing software provisioning across commercial projects to ensure everyone has the exact tools they need. You are currently provisioned with Microsoft Project Plan 3 (designed for full desktop scheduling). We are evaluating which staff require this heavy desktop client, versus the modern Planner Plan 1 interface accessible directly inside Microsoft Teams and your web browser.

Planner Plan 1 (Browser & Teams) Project Plan 3 (Heavy Desktop Client)
Designed for Team Collaboration:
  • Interactive Gantt Timeline views directly in Microsoft Teams.
  • Kanban boards, task lists, checklists, and grid views.
  • Setting task dependencies (predecessors & successors).
  • Attaching photos, specs, and status progress from mobile or iPad.
 Designed for Dedicated Schedulers:
  • Installs the standalone Project.exe app on desktop PC.
  • Authoring complex .mpp files, tender critical paths, and baseline variance calculations.
  • Advanced resource leveling across multi-project portfolios.
